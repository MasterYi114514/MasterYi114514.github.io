1.2 生成缓冲对象（glGenBuffers）

glGenBuffers函数用于生成一个或多个缓冲对象的名称（ID），并将其存储在指定的变量中。

函数原型 glGenBuffers(GLsizei n, GLuint *buffers);

  • n：要生成的缓冲对象的数量。
  • buffers：指向一个无符号整数数组的指针，用于存储生成的缓冲对象名称。
GLuint VBO;
glGenBuffers(1, &VBO);          // 生成一个顶点缓冲对象

GLuint VBOs[2];
glGenBuffers(2, VBOs);          // 生成两个顶点缓冲对象

1.3 绑定缓冲对象（glBindBuffer）

glBindBuffer函数用于绑定一个缓冲对象到一个特定的绑定点上。

函数原型 glBindBuffer(GLenum target, GLuint buffer);

  • target：指定要绑定的缓冲对象的类型。
  • buffer：要绑定的缓冲对象的名称（ID）。
glBindBuffer(GL_ARRAY_BUFFER, VBO);             // 绑定顶点缓冲对象
glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, EBO);     // 绑定索引缓冲对象

参数里的 target 可以是以下几种类型： // 待补充

1.4 缓冲数据（glBufferData）

glBufferData函数用于创建并初始化缓冲对象的数据存储。

函数原型 glBufferData(GLenum target, GLsizeiptr size, const void *data, GLenum usage);

  • target：指定要初始化的缓冲对象的类型。
  • size：指定要分配的缓冲区大小。
  • data：指向要复制到缓冲区的数据的指针。
  • usage：指定缓冲区的使用方式。
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);          // 初始化顶点缓冲对象
glBufferData(GL_ELEMENT_ARRAY_BUFFER, sizeof(indices), indices, GL_STATIC_DRAW);    // 初始化索引缓冲对象
